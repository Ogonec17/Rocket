## Как читать статусы

DOCUMENT_AVAILABLE означает наличие файла, DESIGN_ALIGNED — согласованное с пунктом проектное решение. DIGITAL_FIT_ONLY, DESIGN_ONLY, NUMERICAL_ONLY и SOFTWARE_ONLY относятся лишь к названному типу свидетельства. OPEN/EXTERNAL_OPEN/SOURCE_CONFLICT требуют действий. Ни один статус не означает лётный допуск. NOT_APPLICABLE применяется только к условным требованиям, не относящимся к нынешней одноступенчатой схеме с ПУ организаторов.
